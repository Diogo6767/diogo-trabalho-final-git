# Grandes Músicos da História

> Landing page dedicada a artistas que marcaram a história da música e influenciaram diferentes gerações.

## Sobre o projeto

**Grandes Músicos da História** é uma landing page desenvolvida para apresentar artistas de diferentes períodos e gêneros musicais, destacando sua contribuição para a música e seu impacto cultural.

O projeto foi desenvolvido com foco em uma estrutura semântica, navegação simples e uma apresentação visual responsiva.

---

## Funcionalidades

- Navegação interna entre as seções da página
- Seção de apresentação do projeto
- Cards com informações sobre os artistas
- Fotografias dos artistas
- Identificação dos principais gêneros musicais
- Linha do tempo da evolução da música
- Seção dedicada ao legado dos artistas
- Layout responsivo para diferentes tamanhos de tela
- Navegação por âncoras utilizando HTML

## Tecnologias

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web:

- **HTML5** — estrutura e semântica da página
- **CSS3** — estilização, layout, responsividade e efeitos visuais

### Dependências

O projeto não utiliza frameworks ou bibliotecas JavaScript.

Não é necessário instalar dependências para executar a página.
